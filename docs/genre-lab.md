# genre-lab — ジャンル設計ツール利用ガイド

`genre-lab` は、ジャンル定義（閾値）・カード分岐・ベイズ収束の相互作用を **リアルタイムに可視化** する開発者向けツール。閾値やカードを調整したときに「どのジャンルへ、どれくらいの確率で収束するか」を、実データ（本物の `genreResolver` / `sampleCards`）を使って確認できる。

- 実装: `src/tools/genreLab.ts`（UI）/ `src/tools/genreLabSim.ts`（シミュレーション層）/ `tools/genre-lab.html`（エントリ）
- 開発専用。本番ビルドは `index.html` のみを入力とするため、**dist には含まれない**

---

## 起動方法

```bash
npm run dev
```

dev サーバー起動中に **http://localhost:5173/tools/genre-lab.html** を開く。ページ上部にジャンル数・カード数が実データから読み込まれていれば正常。

---

## 画面の見方

### 1. 実プレイ再現（2択モード）

`2枚引く` で本物の `sampleCards` が2枚を提示する（提示ロジック・重み付けは実ゲームと同一）。片方を選ぶと軸が加算され、事後確率が更新される。`1つ戻す` / `リセット` で操作をやり直せる。ラウンド上限は実ゲームと同じ `MAX_ROUNDS`。**実際のプレイ感に最も近い確認方法。**

### 2. 軸パラメータ（直接操作）

12軸（`tempo` / `range` / `enemy` / `combo` / `growth` / `rhythm` / `stealth` / `vertical` / `aerial` / `survive` / `craft` / `speed`）のスライダーで累積値を直接いじり、「この軸をここまで積んだらどのジャンルになるか」を即座に見る。カード経由では作りにくい極端な組み合わせの検証に向く。

### 3. カード一覧から直接選ぶ

全カードプールを検索・フィルタし、任意のカードをクリックして加算できる。特定カードが事後確率に与える影響をピンポイントで見たいときに使う。

### 4. ジャンル事後確率（収束ガイド）

各ジャンルの事後確率をライブ表示。行にホバーすると **閾値の充足状況**（どの軸が足りているか）が出る。収束判定は実ゲームと同じ基準:

- 最尤ジャンルの確率が `minProb`（`bayes.json`、既定 0.30）以上
- かつ2位の `dominanceRatio` 倍（既定 1.5）以上

両方を満たすとそのジャンルに収束（`base` はランキング対象外）。

### 5. 試作ジャンルを一時追加

`id` / `label` / `thresholds` だけの最小 JSON を貼って `反映` すると、そのジャンルを候補に混ぜて事後確率・収束・到達性を試せる。良さそうなら `正規化JSONをコピー` で `schemas/genre.schema.json` 準拠の JSON を取得し、`src/data/genres/<id>.json` に保存する。

### 6. カードプール到達性シミュレーション

`実行` でモンテカルロを回す（ランダムプレイヤー / 狙い撃ちプレイヤー）。

- **randomDist**: 何も考えずに選んだときの各ジャンル到達率
- **focusedRate**: そのジャンルを狙って最善手を選び続けたときの到達成功率

到達率が極端に低いジャンルは、**閾値が高すぎる** か、**その軸を供給するカードが足りていない**。試作ジャンルを反映中ならそれも計算に含まれる。

## CLI 版（reach-sim）との関係

同じ到達性シミュレーションは CLI でも回せる:

```bash
npm run reach-sim
```

（`scripts/genre-reach-sim.mjs`）。GUI が「1ケースを触って理解する」用途なのに対し、CLI は全ジャンルの到達率を一覧で吐くので **回帰チェック / CI 的な用途** に向く。カードや閾値を変えたら、どちらかで到達性を再測定すること。

> ロジックは両方とも `src/domain/genreResolver.ts` を基準にしている（GUI/シミュレーション層は直接 import、CLI は .mjs のため再実装）。挙動を変えたら両方で確認する。`genreLabSim` のロジックは `tests/unit/tools/genreLabSim.test.ts` で回帰検知している。
