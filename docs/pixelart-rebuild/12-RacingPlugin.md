## 変更方針（PixelArt化の仕様）

### 1. 観客席・横断幕（`drawFarLayer`）

| 要素 | 変更 |
|---|---|
| 観客席のシルエット | `px.ridge()` または `px.rect()` の段状。**観客の頭を 1 セルの点として散らす**とドット絵らしくなる |
| 横断幕 | 既に矩形。`px.rect()` へ |
| 速度光の筋 | `stroke` の細い線を `px.rect()` の横長ブロックへ。**流れる位置の計算式は変更しない** |

観客の点の配置は決定論的ハッシュで決め、フレーム間でちらつかせない。

### 2. 路面・ガードレール（`drawMidLayer`）

| 要素 | 変更 |
|---|---|
| センターライン | 既に破線の矩形。座標の `_snap` のみ。**流れる速度の計算式は変更しない** |
| ガードレールの支柱 | `px.rect()` の縦棒 |

レースゲームの路面表現は「等間隔に流れる破線」であり、
既にドット絵的な構造になっている。

### 3. スポーツカー（`drawPlayer`）→ スプライト（**現状の視点のまま**）

`player-racecar.json` へ。**Q6 の回答により、視点（やや上から見た構図）は変更しない。**
現状の形状をそのままドット化するだけにとどめる。

| 部位 | 現状 | 変更後 |
|---|---|---|
| 車体 | `_roundRect` の角丸ボディ | スプライト。角丸は 1 セルの角落としで表現 |
| ルーフ・フロントガラス | `_roundRect` / パス | スプライトに含める |
| ヘッドライト | `shadowBlur` のグロー | 明色 1〜2 セル + 前方への `px.halo()` |
| ホイール | `arc` の円 + ハブ | ブロック円としてスプライトに含める |

**ホイールの回転**: 現状 `runCycle` で回転している場合、
スプライトの 2 フレーム（ハブの模様の位相違い）で表現する。
`runCycle` の引数はそのまま使い、新しい状態は追加しない。

### 4. 変更しないもの

- `skyColors` / `groundColors` / `farLayerColor` / `midLayerColor` /
  `starColor` / `palette` の色の値
- `spawnTable`
- センターライン・速度光の流れる速度と位置の計算式
- 観客席・ガードレールの配置ハッシュ

   ただし未完成ジャンルのため、軽微であれば追加調整はしない。
