## 4. ゲームロジック上の確認済み不具合

- **重要度**: Critical
- **確信度**: 静的確認済
- **根拠**:

- **備考**: `d9bb0f2` では除去・kills更新・ジャンルフックが実装されていたが、後続変更で消失した。

### 4.2 G-02: hack_slash のEXP機能とスコア項が常時無効

- **重要度**: High
- **確信度**: 静的確認済
- **根拠**:

### 4.3 G-03: hack_slash と tetris の到達率が付属シミュレータで0.0%

- **重要度**: Critical
- **確信度**: 実行確認済

### 4.4 G-04: 同一フレームで複数ハザードから多重ダメージ

## 5. JSON駆動・ハードコーディング違反

### 5.1 J-01: テーマカラーJSONが全体UIに接続されていない

- **重要度**: High
- **確信度**: 静的確認済
- **根拠**:
  - `src/data/config/genres.json:4-116` にテーマ色が定義されている。
  - `src/App.vue:279-288` がJSONから生成するのは `--genre-btn-*` のみで、`App.vue:518` のギブアップ領域だけに適用する。
  - 一方、全体テーマの `--genre-accent` / `--genre-border` / `--genre-bg` 等は `src/styles/global.css:55-174` に15テーマ分が直接記述されている。
- **影響**: JSONのテーマ色を変更してもギブアップUI以外へ反映されず、JSONとCSSが容易に不一致になる。
- **仕様違反**: `CLAUDE.md:264` の「CSS ハードコードなし」と直接矛盾する。

### 5.2 J-02: Canvas側の色・描画調整値がTSへ大量に残る

- **重要度**: High（保守性・データ駆動性）
- **確信度**: ハードコードの存在は確認済。どの値までJSON化対象とするかは仕様書内部に一部矛盾あり。
- **根拠**:
  - `src/genres` だけで、色リテラルを含む行を237行確認した。
  - PixelArtコミットは色リテラル行を127行追加、206行削除している。純減であっても、追加127行がJSON駆動であることにはならない。
  - 例: `AerialStgPlugin.ts:22-103` は空・地面・雲・HUD・HPバー・機体・炎などをTSのreadonlyオブジェクトへ集約する。コメントの「ハードコード回避」は、値の集約であってJSON化ではない。
  - `src/data/genres/*.json` の `bgColor` はCanvas背景経路では使用されず、`sideScroller` はプラグインの `skyColors` / `groundColors` を使う。
- **影響**: 色・演出調整にコード修正と再ビルドが必要で、JSONだけで変更・追加できない。
- **注意**: 座標計算の実装定数まで一律違反とはしていない。少なくともパレット、HUD色、パララックス設定、ハザード視覚設定はデータ化対象と判断する。

### 5.3 J-03: ゲームルールとフォールバックがコード直書き

- **重要度**: Medium
- **確信度**: 静的確認済

- **影響**: JSON追加だけの拡張で暗黙のTSルールが混入し、設定変更が反映されない。

## 6. JSONスキーマ・検証基盤の不備

### 6.1 V-01: `npm run validate` がスキーマ違反を成功扱いにする

- **重要度**: High
- **確信度**: 実行確認済 + 静的確認済

- **しかし実データは次のスキーマ違反を含む**:

- **確信度**: 静的確認済
- **根拠**: `App.vue:520` のギブアップボタンと `ManualPanel.vue:52` の履歴ボタンが `tabindex="-1"`。説明書本体のクリック操作にもbutton相当のキーボード操作がない。
- **影響**: キーボードのみの利用者が、マウス操作と同じUIへ到達できない。
- **補足**: Spaceキーとの競合回避意図はコメントにあるが、別キー・イベント制御・フォーカス時の伝播抑止等で解決すべきで、フォーカス対象から外すのは不親切である。

## 9. 疑惑・未確認事項

以下は今回、確定不具合として数えていない。

1. D7（ビネットの同心縞）とD8（ディザのちらつき）は、ブラウザ描画の目視が必要で未確認。
2. モバイル実プレイは移動・ジャンプ等がキーボード中心で、ThrowOverlay以外のtouch操作が見当たらない。モバイル対応が製品要件なら「プレイ不能」に近いが、明示要件を確認できなかったため疑惑に留める。
3. Playwright 78件はブラウザ実体不足で開始できなかった。テスト失敗を製品不具合とは扱わない一方、今回の監査では実ブラウザによる回帰確認が欠落している。

## 10. 推奨修正順

1. R-01/R-02、および Survival残留敵・到達率0%を解消する。

## 11. 最終所見

PixelArt変更そのものはtypecheck・lint・buildを通過しているが、現行ブランチをリリース可能とは判断できない。とくに、過去に修正済みと記録された重大欠陥が再混入していること、そしてJSON検証が成功表示を返しながら実データのスキーマ違反を見逃すことは、個別バグ以上に再発性の高い問題である。

また、ハードコードは単に行数が減ったかではなく、「JSONの変更だけで製品挙動・見た目が変わるか」で判定すべきである。現状はテーマJSON、ジャンル `bgColor`、BGM設定、Canvasパレットの複数箇所でその条件を満たしていない。

**最終判定: 修正および再監査が必要。**
