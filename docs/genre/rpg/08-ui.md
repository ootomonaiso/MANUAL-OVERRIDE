# 08. 戦闘画面 UI

対象範囲: 設計文書「戦闘画面のUI構成」

---

## 前提

**操作環境は PC のみを想定する。** タッチ環境への対応は考慮しない。
ただし**マウスオーバーだけで開閉する表示は置かない**（スキル枠へ手を伸ばす途中で一覧が勝手に伸び縮みし、
狙った枠が動いてしまうため）。開閉はクリックで行う。

---

## 画面配置

**手前側にプレイヤー、奥側に敵**を配置する。敵は `adjacent3` フォーカスが成立するよう、奥側で**左右方向に並べる**。

背景（`BattleBackdrop`）の上にキャラクターを重ね、右上に進行表示（`TurnIndicator`）を置く。

```
┌──────────────────────────────────────────────┐
│  行動順キュー・敵の次スキル      [第N戦/ターンM]│
├────┬─────────────────────────────────────────┤
│ ス │        ── スキル名の提示（帯）──         │
│ テ │        [敵1]  [敵2]  [敵3]   ← 奥側     │
│ テ │         ▔▔▔    ▔▔▔    ▔▔▔               │
│ ｜ │        HPバー・現在値/最大値             │
│ タ │                                          │
│ ス │                                          │
├────┤              [自キャラ]     ← 手前側     │
│ ス │               ▔▔▔▔▔▔▔                   │
│ キ │              HPバー・現在値/最大値        │
│ ル │              シールド残量                 │
│ 一 │                                          │
│ 覧 │   ┌──────────────────────────────────┐  │
│    │   │ アクティブ4枠 / 守る / 何もしない │  │
│    │   │ 各アイコン下に Lv・スタック・CT   │  │
└────┴───┴──────────────────────────────────┴──┘
```

コンポーネント構成:

| コンポーネント | 役割 |
|---|---|
| `BattleScreen.vue` | 戦闘画面全体のレイアウト。以下を配置する |
| `StatusPanel.vue` | 左側・折りたたみ式のステータス表示 |
| `SkillListPanel.vue` | 左側・折りたたみ式のスキル一覧 |
| `TurnQueueBar.vue` | 行動順・敵の次スキル公開 |
| `CharacterFrame.vue` | キャラ + HPバー + 現在値/最大値（自敵共通） |
| `ActiveSkillBar.vue` | アクティブ4枠 + 守る/何もしない |
| `FocusSelector.vue` | 対象選択 |
| `CharacterDetail.vue` | クリック時の詳細表示 |
| `SkillDraftPanel.vue` | 撃破後の3択 |
| `SkillText.vue` | 効果文の色分け |
| `BattleBackdrop.vue` | 背景（`src/data/battle-backgrounds/*.json` を SVG で描く） |
| `PixelSprite.vue` | ドット絵1体分の描画（`src/data/sprites/*.json` を SVG 矩形へ展開） |
| `SkillCastBanner.vue` | 行動直前に出すスキル名の帯 |
| `TurnIndicator.vue` | 画面右上の「第N戦 / ターンM / 誰の手番か」 |

演出の振り分け（ポップアップ・フラッシュ・効果音・画面シェイク）は
コンポーネントではなく `composables/useBattlePresentation.ts` が担う（[09-effects.md](09-effects.md)）。

## ステータス表示パネル

画面左側に配置し、**畳んだ状態でもいつでも開いて確認できる**。

### 表示切替トグル（2軸・4パターン）

| 軸 | 選択肢 |
|---|---|
| 表示する値 | **基礎値** / **実効値** |
| バフ差分の表示 | **オン** / **オフ** |

表示例（基礎値 `10000`、実効値 `15000`）:

| 設定 | 表示 |
|---|---|
| 基礎値・バフオフ | `HP : 10000` |
| 実効値・バフオフ | `HP : 15000` |
| 基礎値・バフオン | `HP : 10000 +5000` |
| 実効値・バフオン | `HP : 15000 +5000`（`+5000` を**灰色**で目立たなく） |

**`+5000` は「実効値と基礎値の差」であり、実数バフの値ではない。** 実数バフと倍率バフの両方を適用した結果の差分を表示する。

```ts
const diff = computed(() => effective.value - base.value)
```

実効値表示時に差分を灰色にするのは、主たる情報が実効値そのもので差分は補足に過ぎないため。

### 差分の符号

差分が負（デバフ）の場合は `-3000` のように符号を付けて表示する。色は差分の正負で分ける（正=強調色、負=警告色、実効値表示時は両方とも灰色）。

> **決定（Q12）**: デバフが存在する以上、負の差分は起こりうるため **符号付きで表示し色で区別する**。

### トグルの永続化

トグルの選択状態は**戦闘をまたいで保持する**（ラン中は維持）。ラン終了でリセットする。

## スキル一覧パネル

ステータス表示パネルの近くに配置する。**折りたたみ式**。

### 表示順

**上部（所持しているもの）**

1. セット中のアクティブスキル
2. パッシブスキル
3. 特性

**下部（未入手のもの）**

1. 未入手のアクティブスキル
2. 未入手のパッシブスキル
3. 未入手の特性

保管中（枠から外した）アクティブスキルは、**所持側の「セット中のアクティブスキル」の後**に、保管中と分かる形で表示する。

> **決定（Q13）**: 所持しているものである以上、未入手側ではなく **所持側** に置く。

### 未入手の開示段階

未入手のものは**スキル名のみ**を表示し、**アイコンは灰色**にする。効果の詳細は伏せる。

一度でも目にしたものは順次開示される（[06-draft.md](06-draft.md) の既見フラグ）。

| 状態 | 表示 |
|---|---|
| 未見 | 名前のみ・アイコン灰色・効果は伏せる |
| 既見（未入手） | 効果も表示・アイコン灰色 |
| 所持 | 効果も表示・アイコン通常色・レベルとスタックも表示 |

### 操作

- **クリック**: 詳細を開く／閉じる

同時に開くのは**1つのみ**。別の項目をクリックすると切り替わる。

> **決定（改修時）**: 当初はマウスオーバーでも開く設計だったが、カーソルが通過するだけで
> 一覧の高さが変わり、下にあるスキル枠が動いてしまうため**ホバーでの開閉は廃止した**。
> クリックでの開閉は変更していない。

## キャラクター表示

自キャラ・敵キャラの双方に表示する（`CharacterFrame.vue`）。

| 要素 | 内容 |
|---|---|
| スプライト | `PixelSprite`。通常は `idle`、行動中は `attack` フレーム |
| 足元の影 | 楕円のグラデーション。無いと地面から浮いて見える |
| HPバー | 現在HP / 最大HP の比率 |
| 数値 | `現在HP / 最大HP` |
| シールド | 残量がある場合のみ、HPバーの上に重ねて表示 |
| 状態異常・バフ | アイコンで表示（該当がある場合） |

### 見た目の出どころ

| 対象 | スプライトIDの指定場所 |
|---|---|
| 敵 | `src/data/enemies/*.json` の `sprite`（[07-data-schema.md](07-data-schema.md)） |
| プレイヤー | `src/data/config/battle.json` の `playerSprite` |

プレイヤーは**奥の敵の方を向いた後ろ姿**として描く（プレイヤーの視点＝画面の手前側に立たせるため）。

### 行動中の見た目

行動する側は `attack` フレームに差し替わり、CSS で相手側へ踏み込む
（敵は手前へ、プレイヤーは奥へ）。**これは行動順がどちらでも同じ**。

### 被弾の見た目

被弾した側は一瞬だけ単色のシルエットになる。色は原因で変える。

| 状況 | 色 |
|---|---|
| ダメージ | 赤 |
| シールドで受けた | 青 |
| 回復 | 緑 |

`PixelSprite` の `tint` に色を渡すと全セルがその色で塗られる。
フィルタではなく塗り替えなのは、ドット絵の輪郭を保ったまま確実に色が変わるため。

### 自キャラ下部のアクティブスキル表示

各アイコンの下に以下を表示する。

| 表示 | 内容 |
|---|---|
| レベル | `Lv2` 等 |
| スタック | `2/3` のように「現レベルで貯まっている数 / 次レベルに必要な数」 |
| クールタイム | 残ターン数。0 なら非表示 |

クールタイム中のスキルは**選択不可**とし、視覚的にも区別する（暗くする等）。

### 敵の撃破表示

撃破された敵は配列から削除されない（`alive: false`）。表示上は**撃破済みと分かる形で残す**（暗転・グレーアウト）。位置関係が変わらないことを視覚的に示すため。

## キャラクター詳細表示

**自キャラ・敵キャラともにクリックで開く。**

| 表示内容 | |
|---|---|
| 10ステータス | **実効値**および**基礎値** |
| 特性 | 所持している特性の一覧 |
| パッシブスキル | 同上 |
| アクティブスキル | 同上 |
| フレーバーテキスト | 上記それぞれのもの |

### 敵の行動パターンは非公開

**`actionPattern` の並びは表示しない。** 「どのスキルを持っているか」は分かるが「どの順で使ってくるか」は分からない。

次に使うスキルは `TurnQueueBar` で1手先だけが読める、という情報量に留める。

### 既見フラグの更新

**敵の詳細表示を開いた時点**で、その敵の所持スキル・特性に既見フラグを立てる。

## 行動順キュー表示（`TurnQueueBar`）

| 表示 | 内容 |
|---|---|
| 行動順 | そのラウンドの順序。誰が次に動くか |
| 現在の手番 | 強調表示 |
| 敵の次スキル | 各敵が次に使うスキル名と属性 |

---

## 進行表示（`TurnIndicator`）

画面**右上**に常時表示する。行動順キューが「誰が動くか」を示すのに対し、
こちらは「いまどこまで進んだか」を示す。

| 表示 | 内容 |
|---|---|
| 第N戦 | `battleIndex + 1` |
| ターンM | `roundCount + 1`（1ラウンド = 全員が1回動く） |
| 手番 | `あなたの手番` / `<敵名>の手番` |
| 場所 | 現在の背景のラベル（例: `禍々しい荒れ地`） |

---

## スキル名の提示（`SkillCastBanner`）

行動が解決される**前**に、誰が何を使うのかを戦場の上端に帯で出す。
属性色（物理=橙赤 / 魔法=青 / 特殊=紫）で縁取る。

- **プレイヤーと敵で同じ形式**にする（行動順がどちらでも手応えを揃えるため）
- 中央ではなく上端に置く（中央だと敵が隠れ、何に当たったのか見えなくなる）
- 同じスキルを連続で使ってもアニメーションを撃ち直す（`presentation.seq` をキーにする）

---

## 対象選択（`FocusSelector`）

スキルを選ぶと対象選択に移る。

- デフォルトフォーカスが初期選択される
- `range` に応じて対象がハイライトされる（`single` は1体、`all` は全体、`adjacent3` は中心と左右）
- 対象を確定すると効果解決へ進む
- キャンセルで行動選択へ戻る

`side: 'self'` かつ `range: 'single'` のスキル（自己回復等）は**対象が自明なため選択をスキップする**。

---

## ドラフト画面（`SkillDraftPanel`）

3つの選択肢をカードとして横に並べる。各カードに表示するもの:

| 表示 | 内容 |
|---|---|
| 名前 | スキル・特性名 |
| 種別 | アクティブ / パッシブ / 特性 |
| カテゴリ | メイン（+サブがあれば併記） |
| 効果 | `SkillText` による色分け表示 |
| フレーバーテキスト | |
| 重複取得の場合 | `Lv2 → Lv3` のようにレベル変化を明示 |
| 解放枠の場合 | 「解放」バッジ |

アクティブスキルを選んで枠が全て埋まっている場合、**入れ替え先を選ぶ画面へ遷移する**。キャンセルでドラフト選択へ戻る。

## 色の扱い

**色は CSS 変数として定義し、ハードコードしない。** 既存の `GENRE_THEME_COLORS`（`src/data/config/genres.json`）と同じ流儀に従う。

必要な色:

| 用途 | 変数名（案） |
|---|---|
| 属性: 物理 / 魔法 / 特殊 | `--battle-element-physical` 等 |
| ステータス名 | `--battle-stat` |
| 数値 | `--battle-number` |
| バフ差分（正 / 負 / 補足） | `--battle-diff-plus` / `--battle-diff-minus` / `--battle-diff-muted` |
| カテゴリ11種 | `--battle-category-<id>` |
| アクセント（見出し・強調） | `--battle-accent` |
| パネル地色 | `--battle-panel` |
| 文字色 | `--battle-text` |

`--battle-accent` と `--battle-panel` は**背景JSONが上書きする**（`BattleScreen` が
インラインスタイルで注入）。草原では金、荒れ地では朱、遺跡では藤色というように、
戦っている場所に合わせてUIの色も変わる。他の変数は `.battle-screen` に既定値を持つ。

パネル類は `color-mix()` で半透明にし、背景の上に重ねても地形が透けて見えるようにする。

## エッジケース

| ケース | 扱い |
|---|---|
| 敵が3体を超える | 横に並べる。上限は `battle.json` で定義し、はみ出さない範囲に収める |
| スキル一覧が長い | パネル内でスクロールさせる。画面全体はスクロールさせない |
| 詳細ポップアップが画面外にはみ出す | 表示位置を反転させる |
| 折りたたみ状態でドラフト発生 | ドラフト画面はパネルより前面に出す |
| 敵が全員撃破済みの瞬間 | ドラフトへ遷移するまでの間、撃破演出を再生する |

## 実装後の記録

### 見た目まわりの改修（後追い）

| 変更 | 理由 |
|---|---|
| 背景を5種追加（`BattleBackdrop`） | 単色背景では戦っている場所が伝わらず、連戦が同じ絵に見える |
| キャラをドット絵にした（`PixelSprite`） | 名前とHPバーだけでは誰と戦っているのか分からない |
| 攻撃専用フレームを必須にした | 行動しても絵が変わらないと、当たったのかどうかが読めない |
| スキル名の帯・ダメージポップアップ・被弾フラッシュを追加 | 1手番が一瞬で終わり、何が起きたのか追えなかった |
| 右上に進行表示を追加 | 何ターン目・誰の手番かが画面から読み取れなかった |
| スキル一覧のホバー展開を廃止 | カーソルの通過で一覧の高さが変わり、下のスキル枠が動いてしまう |
| パネル色を背景JSONから受け取るようにした | 背景を敷いた結果、既存の緑基調のパネルが浮いていた |

### 実装時に見つかった不具合

- **スキル枠の「何もしない」が押せない**: アクションバーが画面中央基準で、右下の説明書パネル
  （幅340px前後）の下に最後の枠が潜り込んでいた。アクションバーに `margin-right` を入れて回避。
