## 概要

深海を舞台に、プレイヤーがひたすら下へ潜り続ける水中アクションゲーム。画面はゆっくりと自動的に下へスクロールし、画面下から横方向に長い岩が次々と出現する。プレイヤーは重力の小さい浮遊感のある挙動で岩から岩へ跳び移りながら、スクロールに取り残されないよう潜り続ける。酸素ゲージは廃止し、画面外への逸脱そのものが敗北条件になる。深く潜るほどスコアが高くなる点は従来の案から変更なし。

## 本セッションでの確定事項

| 論点 | 結論 |
|---|---|
| 上下方向の操作 | 自由な上下移動はしない。重力に従って自然に落下し、ジャンプキーで小さく上方向へ勢いをつけられる程度（大きな滞空・自由飛行はしない） |
| 重力・ジャンプの強さ | 重力はかなり小さく、ゆったり降りていく。ジャンプも小さい（軌道の微調整用途。Platformer のような主要な移動手段ではない） |
| 水平方向の操作 | `←→` で自由に移動する（変更なし） |
| 画面レイアウト・カメラ | `aerial_stg` の縦スクロールカメラ・画面サイズ実装をそのまま流用。左右をパネルで埋め、水平可動域を視覚的にわかる帯に制限する（`platformer` と同じ扱い） |
| スクロール | 遅めの定速自動縦スクロール。時間経過で緩やかに速度上昇、上限あり（Runner/Platformer と同じ考え方。従来の距離ベース難易度曲線は使わない） |
| 敗北条件 | **画面外に出たら即敗北**。(1) 上方向: スクロールに置き去りにされ画面上端から消える、(2) 下方向: 岩に乗れず自由落下を続け画面下端まで落ちきる。両方とも敗北 |
| 地形（岩） | 横方向に長い岩が画面下から次々出現し、上へ流れていく。乗ると着地でき、下からは素通りできる一方通行足場として扱う |
| 地形生成方式 | **手作りパターン方式**（Runner/Platformer と統一）。岩の間隔・オフセットは到達可能性検証で理不尽にならないよう保証する |
| 酸素ゲージ | **廃止**。HP/oxygen 相当のゲージ概念自体を持たない |
| 回復要素（サンゴ） | **廃止**。回復対象がなくなるため要素ごと削除する |
| 敵接触 | **即死**。ダメージという概念をなくし、他の多くのジャンルの危険ハザードと同じ「接触＝即敗北」に統一する |
| 敵の挙動 | 自力移動しない固定ハザードとして扱う（Runner の「トゲ」と同じ考え方）。ステージと一緒に流れるのみで、追跡等はしない |
| ふわふわ移動する足場 | 岩より小さく、左右にゆっくり往復し続ける足場（既存の `driftEnabled` 機構を流用） |
| 流れが強い場所 | ゾーン内にいる間、**水平方向（左右）**に強制的に押し流されるゾーン。垂直方向への影響は持たない |
| スコア | 深度（`distance`）のみのシンプルな式。サンゴボーナス等は持たない |

## ゲーム仕様

### 核となる体験

- **目的**: できるだけ深く潜る。到達最大深度をスコア化
- **自動スクロール**: 画面が一定の遅い速度で自動的に下へスクロールし続ける。時間経過でわずかに加速するが上限あり
- **岩**: 画面下から出現し、横方向に長い岩状の足場が次々に流れてくる。上に乗ると着地でき、下からジャンプで突き上げても素通りする（一方通行足場）
- **プレイヤーの垂直挙動**: 重力は小さく、ゆったりと落下する。小さくジャンプもできるが、軌道の微調整程度で大きな滞空時間は持たない
- **プレイヤーの水平挙動**: `←→` で左右移動。可動域は画面左右のパネルで区切られた帯の中に制限される
- **乗り継ぎ**: 岩の上に着地してから、スクロールに追い抜かれる前に次の岩へ跳び移ることを繰り返し、下へ進み続ける
- **上方向の敗北**: 1つの岩の上に長く留まりすぎる、またはジャンプで浮きすぎると、自動スクロールに置き去りにされ画面上端から見えなくなる → 敗北
- **下方向の敗北**: 岩を外して自由落下を続け、画面下端まで落ちきる → 敗北
- **敵**: 岩と同様にステージと一緒に流れてくる固定ハザード（自力移動なし）。接触すると即座に敗北
- **ふわふわ足場**: 通常の岩より小さく、左右にゆっくり往復し続ける足場。足場自体が動くため、飛び移りのタイミング調整が必要になる
- **流れが強い場所**: 接触ではなく重なっている間、水平方向へ強制的に押し流されるゾーン。岩の隙間への着地精度を狂わせる要素として機能する
- **難易度上昇**: 時間経過に応じてスクロール速度が緩やかに上昇する。上限を設け、操作で対応不可能な速度には到達させない

### 操作方法（更新）

| キー | 動作 |
|------|------|
| ← → | 左右移動 |
| Space（仮） | 小さくジャンプ |
| ↑ ↓ | 使用しない |

## ビジュアル（更新）

- 深い青色を基調とした深海。既存の `environment: ocean` テーマを維持
- 岩はゴツゴツした岩肌のシルエットで、横に長い塊として描画する（既存のサンゴ描画は役割を岩に差し替え、サンゴ自体は削除）
- 敵は棘・牙を思わせる危険な魚のシルエット（Runner の「トゲ」と同じ「敵＝固定ハザード」の考え方だが、水中らしい生物モチーフにする）
- ふわふわ足場は岩と見分けがつくよう、小さめ・やや発光する見た目にする
- 流れが強い場所は、水流の向きが視覚的にわかる演出（気泡・水流線のパーティクルなど）を入れる
- 画面左右のパネルは、可動域の境界が一目でわかるようにする（`aerial_stg`/`platformer` と共通の見た目方針）

## 実装上の注意点（更新）

- 地形生成は Runner/Platformer と同じ「手作りパターンを JSON で定義し、プールから選んで連結する」方式を採用する。ただし連結方向が横（Runner）でも部屋クリア（Platformer）でもなく、**縦方向にエンドレス連結する第3の形**になる（詳細は [`spec-aquatic.md`](spec-aquatic.md)）
- 岩の間隔・オフセットは、重力の小さい浮遊感のある自由落下でも到達可能かを検証できるよう、Runner/Platformer の reach-sim とは異なる検証ロジック（落下時間内に画面外まで落ちきらないか、横移動が間に合うか）が必要になる
- 酸素ゲージ廃止に伴い、既存の `player.hp`/`maxHp` を流用する設計（旧版の決定）は不要になる。プレイヤーはライフ概念自体を持たず、敗北は「画面外への逸脱」「敵接触」のみで判定する
- 重力・ジャンプ初速度は Aquatic 専用の小さい値を使うため、既存の共通ジャンプ物理（`physics.json` 固定値前提）をそのまま使わず、Aquatic 専用 Feature が独自に管理する
